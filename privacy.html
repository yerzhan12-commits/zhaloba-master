Жалоба

Политика конфиденциальности

Какие данные собираются

Сервис «Жалоба» обрабатывает только данные, которые пользователь сам вводит для формирования обращения: текстовое описание ситуации, ответы на уточняющие вопросы, прикреплённые фото/PDF-файлы как доказательства. Указывать ФИО, ИИН и другие персональные данные для получения черновика не требуется.

Как используются данные

Введённые данные используются исключительно для формирования текста обращения. Результат хранится на сервере временно — не более 5 дней с момента создания, после чего автоматически удаляется. Данные не передаются третьим лицам и не используются в рекламных целях.

Данные при оплате

Оплата происходит на защищённой платёжной странице интернет-эквайринга АО «Банк ЦентрКредит». Реквизиты банковской карты вводятся напрямую на стороне банка — сервис «Жалоба» не получает, не видит и не хранит номер карты, срок действия или CVC-код.

Cookies и технические данные

Сайт может использовать локальное хранилище браузера (localStorage) для запоминания истории обращений на устройстве пользователя и статуса бесплатной попытки. Эти данные хранятся только на устройстве пользователя и не передаются на сервер, за исключением случаев, когда пользователь сам инициирует создание или оплату обращения.

Права пользователя

Пользователь может в любой момент удалить историю обращений на своём устройстве через раздел «Мои обращения» в приложении. По вопросам обработки данных можно обратиться по контактам ниже.
